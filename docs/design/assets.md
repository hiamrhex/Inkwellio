## Brand Mark & Favicons
- **Inline Mark (`packages/ui/src/inkwellio-logo.tsx`)**: Sharp concave-tapered fountain-pen nib silhouette (`<svg>`, `< 0.45 KiB`) with no outer circle, tip slit ending in an emerald breather dot (`#10b981` dark / `#0f766e` light), and base bar (`#ffffff` dark / `#0b0c10` light).
- **Favicons (`apps/web/src/app/icon.svg` & `apps/web/src/app/favicon.ico`)**: Adaptive SVG favicon switching on `@media (prefers-color-scheme: dark)` plus multi-resolution `16×16` / `32×32` `favicon.ico` (`1,018 B`) fallback for older browsers.

## Delivery Rules
- Mounted behind `LivingHeroArtifact` (`alt=""`, `aria-hidden="true"`, explicit `width={1280}`, `height={714}`, `srcSet` `-mobile.webp 680w, .webp 1280w`, `sizes="(max-width: 767px) 74vw, 62vw"`, `loading="eager"`, `fetchPriority="high"`).
- `/scripts/theme.js` preloads only the active resolved theme's responsive hero WebP (`fetchpriority="high"`), avoiding dual-theme double downloads.
- `<AuthSpatialBackdrop />` renders lazily only on auth routes (`/sign-in`, `/sign-up`, `/forgot-password`, `/reset-password`, `/verify-email`).
